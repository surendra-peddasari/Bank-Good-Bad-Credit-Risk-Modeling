# Security & Confidentiality

This repository is structured for a professional portfolio representation of a client internship project.

- No database credentials are stored in Git.
- No raw customer-level data is included.
- Do not upload database dumps, exported customer records, passwords, API keys, or confidential client documents.
- Use environment variables for local database access.
- If this repository is public, confirm that the client name, project metrics, feature descriptions, and implementation details are permitted for public disclosure before publishing.
